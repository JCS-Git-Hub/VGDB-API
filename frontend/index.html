Documentación

También puedes probar la API desde Swagger UI o a través de la siguiente dirección:

http://127.0.0.1:8000/docs

Para acceder a los contenidos de la base de datos, introduce una de las siguientes líneas en el navegador:

http://127.0.0.1:8000/api/categories
http://127.0.0.1:8000/api/categories/{category_id}

http://127.0.0.1:8000/api/games
http://127.0.0.1:8000/api/games/{game_id}
